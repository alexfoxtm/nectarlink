spake2-android 2.2.1 (com.github.MuntashirAkon.spake2-java:spake2-android:2.2.1)
The SPAKE2 key exchange used to pair with wireless debugging; a dependency of
libadb-android. It includes the native library lib/<abi>/libspake2.so.

Source: https://github.com/MuntashirAkon/spake2-java tag 2.2.1 (commit 7615ddd680b990e14513ebb66eac4cb0dbf82464)
Native code: https://github.com/MuntashirAkon/spake2-c commit 0d15933e5ba3e662cb01245a7ac0dc9fca3eac31
  (the android/src/main/cpp/spake2-c submodule at the tag above)
Shipped binary: spake2-android-2.2.1.aar from JitPack, SHA-256 8798fb6c04b5d53a6307ed9481e9afe563227abd4e8b9e917c8514fa850071bb

spake2-java is licensed under LGPL-3.0 (its README: "Copyright 2021 Muntashir
Al-Islam. Licensed under the LGPL-3.0"). The LGPL-3.0 builds on the GPL-3.0,
whose text is GPL-3.0-or-later.txt in this list. Its README also states that
its Ed25519 code is a modified and simplified version of EdDSA-Java
(https://github.com/str4d/ed25519-java, CC0).

libspake2.so is built from spake2_jni.cpp and spake2-c's spake2.c and sha512.c
(android/src/main/cpp/CMakeLists.txt). Their own notices are quoted below:
spake2.c and ed25519.h (Google Inc. and Muntashir Al-Islam), curve25519_32.h
(the fiat-crypto authors, MIT License), and sha512.c / sha512.h
(Free Software Foundation and Muntashir Al-Islam, LGPL-2.1-or-later; the
LGPL-2.1 text is LGPL-2.1.txt in this list).

The source for these exact versions is at the URLs above. That the JitPack
binary was built from them is not verified here.

The files below are copied verbatim from those sources.
